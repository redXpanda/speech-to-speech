# ASR 方案对比结论（2026-11-25）

## 测试设置

- 数据集：`voice_data/WenJing.list` 取前 20 条（`wenjing20.tsv`，中文，GPT-SoVITS 标注作参考文本）。
- 指标：字错率 CER（去掉 SenseVoice 的情感/事件标签后计算），单条平均耗时，设备。
- 环境：Python 3.10 独立 venv；SenseVoice / FunASR 用 `funasr==1.4.29` + CPU torch 2.14.1；Whisper 用 `openai-whisper==20250625` + CPU。
- 结果文件：`result_sensevoice.json` / `result_funasr.json` / `result_whisper.json`。

## 结果

| 后端 | 模型 | 设备 | 平均 CER | 平均耗时/条 | 备注 |
| --- | --- | --- | --- | --- | --- |
| FunASR | paraformer-zh + fsmn-vad + ct-punc | CPU | **0.136** | 0.51 s | 效果最好，非自回归 |
| SenseVoice | SenseVoiceSmall + fsmn-vad | CPU | 0.160 | 0.46 s | 最快；自带情感/事件标签， latency 最低 |
| Whisper | whisper-small | CPU | 0.308 | 2.23 s | 中文效果明显落后，且最慢 |

## 结论

- **主推 SenseVoice**：速度最快（0.46 s），CER 0.160 与 FunASR 接近；作为实时语音对话的 STT 最合适，且能顺带输出情感/事件标签。已按用户要求拉到最新（commit `586bbdb`）并重建 venv。
- **FunASR (paraformer-zh)**：CER 最低（0.136），可作为离线/高精度场景备选。
- **Whisper-small**：中文 CER 0.308 明显落后且慢 4~5 倍，不推荐用于本项目中文为主场景。

说明：以上均为 CPU 测试（当前 SenseVoice venv 装的是 CPU 版 torch 2.14.1）。GPU 可进一步降低延迟；CER 基本不受设备影响。参考文本来自 GPT-SoVITS 数据集标注，本身有噪声，绝对 CER 仅供参考，三者横向对比有效。
